Android Studio 使用说明

    
    
      
  • 连接：手机开启 USB 调试后插上电脑；或 adb connect IP:5555 网络连接。服务每 6 秒自动探测。
    • 
      
  • 画面：左侧选刷新档位；MJPEG 流最流畅，但设备端 screencap 每帧约 0.3–1s，真实帧率约 1–2 fps。
    • 
      
  • 触控：画面上点击=轻触、拖拽=滑动；坐标按实时 wm size 的物理像素换算。
    • 
      
  • 横屏：「横屏」按钮通过 user_rotation 强制旋转（多数设备免 root 可用）；「旋转画面」只旋转预览并逆映射坐标。
    • 
      
  • 脚本：Ctrl/⌘+Enter 运行，Ctrl/⌘+S 保存；循环里用 device.sleep() 以便「停止」及时中断。
    • 
      
  • 中文输入：安装 ADBKeyboard 后 device.text("中文") 自动走广播通道。
    • 
      
  • 安全：在线脚本可执行任意 Python，服务默认只监听 127.0.0.1，--host 0.0.0.0 仅限可信局域网。
